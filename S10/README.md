# Campus Service Request System

## Requirements

- Students can submit requests
- Each request has a title
- Each request has a description
- Each request has a status
- Default status is Pending
- Staff can update status
- Users can view request list
- Users can view request details

---

## User Roles

### Student
- Submit request
- View request list
- View request details

### Staff
- View all requests
- Update request status

---

## Use Cases

### Use Case: Submit Request
Actor: Student

Main Flow:
1. Student opens form
2. Student enters data
3. System saves request
4. Status set to Pending

Success Outcome:
Request saved successfully.

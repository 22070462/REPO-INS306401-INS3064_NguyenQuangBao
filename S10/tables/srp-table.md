# SRP Class Responsibility Table

| Class name | Responsibility | Reason to change |
|------------|---------------|----------------|
| Request | Stores request data | Data structure changes |
| RequestRepository | Saves and loads requests | Storage changes |
| RequestService | Handles business logic | Business rules change |
| RequestValidator | Validates input | Validation rules change |
| RequestController | Controls flow | Routes change |
| ViewRenderer | Renders views | UI rendering change |
